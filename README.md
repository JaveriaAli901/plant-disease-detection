# 🌿 Plant Disease Detection System

An AI-powered web application that detects plant diseases from leaf images using Deep Learning.

## Features

- 🌱 Detects 38 plant diseases
- 📷 Upload leaf images
- 🤖 AI-based prediction
- 📊 Confidence score
- 🌐 Streamlit Web App

## Technologies Used

- Python
- TensorFlow
- MobileNetV2
- Streamlit
- OpenCV
- NumPy

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
